# Sistema de Gestión Hospitalaria

Aplicación web orientada a la gestión y seguimiento de procesos hospitalarios.

## Descripción

Sistema desarrollado para facilitar la administración y consulta de información relacionada con pacientes e ingresos hospitalarios.

El proyecto cuenta con diferentes módulos orientados a la gestión de ingresos, autorizaciones, documentos, correos y trazabilidad de la información.

## Funcionalidades

- Autenticación de usuarios
- Gestión de ingresos hospitalarios
- Consulta de información del paciente
- Gestión de autorizaciones
- Gestión de documentos
- Gestión de correos
- Trazabilidad de la información
- Navegación mediante módulos
- Manejo de sesiones de usuario
- Interfaz web responsiva

## Tecnologías utilizadas

### Frontend

- Angular
- TypeScript
- JavaScript
- HTML5
- CSS3
- Angular Material

### Backend

- Java

## Interfaz

El sistema cuenta con una interfaz web diseñada para facilitar la consulta y gestión de la información hospitalaria.

### Inicio de sesión

Pantalla de autenticación para el acceso al sistema.

### Gestión de ingresos

Módulo destinado a la consulta y gestión de los ingresos hospitalarios.

### Información del paciente

Visualización de los datos asociados al paciente y su ingreso.

### Trazabilidad

Visualización del historial de eventos y movimientos relacionados con el ingreso.
